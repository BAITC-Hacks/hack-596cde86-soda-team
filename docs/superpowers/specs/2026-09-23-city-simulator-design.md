# «Аким на 5 часов»: спецификация MVP

## Цель и границы

Рабочий симулятор для жюри хакатона: каждый пользователь видит один и тот же синтетический набор данных и бюджет 100, выбирает ровно пять разных мероприятий и получает воспроизводимый Astana Quality of Life Score, изменения по районам и понятное объяснение. Локальный запуск должен работать без API-ключа. Подключённый OpenAI API улучшает текстовое объяснение через вызовы инструментов, но не участвует в расчётах.

## Данные и расчёт

`data/districts.json`, `data/measures.json` и `data/weights.json` — единственный источник исходных чисел. Пять районов, десять показателей и четырнадцать мероприятий соответствуют приложенному датасету. Горизонт — восемь кварталов. Эффект меры умножается на `(8 - lag) / 8`, затем добавляются немасштабируемые синергии и применяется ограничение 0–100. Оценка района — взвешенная сумма показателей. Итог: `0.7 × средневзвешенная оценка города + 0.3 × оценка слабейшего района − число показателей строго ниже 40`.

Валидация собирает все ошибки: ровно пять мер, нет повторов, бюджет не превышен, район соответствует типу меры, максимум две меры одного направления, несовместимости соблюдены. Невалидный набор не имеет Score. Порядок выбора не влияет на результат.

## Компоненты

- `backend/engine`: Pydantic-модели публичных результатов, загрузчик и проверка датасета, валидатор, симуляция, оценка, вклад мер, сравнение, перебор допустимых наборов и предложения замен. Движок не обращается к сети.
- `backend/api`: FastAPI `/api/data`, `/api/validate`, `/api/simulate`, `/api/explain`, `/api/best`, `/api/health`. Ошибки сценария возвращают HTTP 422 и `{errors: [{rule, message}]}`.
- `backend/ai`: OpenAI Responses API вызывает серверный инструмент с результатами движка. Системный промпт запрещает собственные числа. При отсутствии ключа, таймауте или ошибке используется детерминированный шаблон.
- `frontend`: React/TypeScript/Vite, рабочая панель из каталога мер, полосы бюджета и направлений, результата, сравнений районов и объяснения. Все числа приходят из API.
- Docker Compose запускает API и UI. README фиксирует запуск, тесты, эталоны, архитектуру и ограничения.

## Поведение интерфейса

Пользователь выбирает меру, для районной меры — район. На каждом изменении видит стоимость и ошибки. При пяти валидных решениях нажимает «Рассчитать сценарий». После расчёта видит Score и разницу с базой и оптимумом, изменения показателей по районам, критические значения и объяснение. Выбор можно менять и рассчитывать снова.

## Приёмка

Обязательные эталоны: база 52.558; пример из задания 56.543; оптимум 57.237 стоимостью 98; допустимых наборов 694395; худший допустимый ниже базы. Покрываются отдельные правила валидации, API 422, fallback без ключа и сборка интерфейса. Внешний LLM-текст невозможно сделать строго детерминированным, поэтому все числовые выводы в UI авторитетно берутся из движка; его ответ может быть заменён fallback при ошибке.

## Ограничения

Данные условные, эффекты экспертно заданные и не являются прогнозом для реальной Астаны. Сессии команд и хранение результатов не входят в MVP. `/api/best` запускает полный перебор при первом обращении и кеширует результат в процессе API.
