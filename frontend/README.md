# Интерфейс «Аким на 5 часов»

Основное приложение находится в `src/`. Визуальный источник — предоставленный макет в `frontend_new/`: сохранены палитра, шрифты, иконки, карточки, верхняя панель и оформление набора. Папка макета не участвует в сборке основного приложения.

## Сценарий игры

1. Выберите меры в каталоге и районы для районных мер. Бюджет и направления обновляются сразу; проверку набора выполняет `/api/validate`.
2. Нажмите «Рассчитать Score» после успешной проверки. Результат добавится ниже на той же странице; страница прокрутится к новому сценарию.
3. Под результатом появляются рассчитанный набор, график, таблица показателей и разбор агента с вкладом мер. При ошибке разбора доступен повторный запрос.
4. Измените набор и выполните следующий расчёт. Предыдущий результат остаётся на странице, новый добавляется внизу. История хранится в памяти до перезагрузки.

Неполные наборы не рассчитываются. До расчёта текущего набора HUD явно показывает исходный Score из `/api/data`. Все значения Score, вкладов, сравнений и показателей поступают из существующего API; `/api/preview` не требуется. Правила, несовместимости и идентификаторы районов также берутся из API.

«Районы», «Лучшие наборы» и «Методика» открывают справочные разделы страницы. Лучшие наборы загружаются по запросу, их можно перенести в текущий набор.

## Запуск и проверка

Из этой папки: `npm run dev` (API должен работать на `127.0.0.1:8000`). Проверка TypeScript и production-сборка: `npm run build`. Docker Compose запускается из корня проекта прежней командой `docker compose up`.

Проверка ограничений каталога на реальном датасете (Node 22.18+): `node --test tests/rules.test.mjs`.

Интерфейс адаптирован к узким экранам. Широкая таблица показателей прокручивается горизонтально. Шрифты исходного макета загружаются через Google Fonts; при недоступности используются системные sans-serif и monospace.
